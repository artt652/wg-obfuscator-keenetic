Экземпляры

WireGuard

Сюда подключается WireGuard: Endpoint 127.0.0.1:порт
127.0.0.1 — только внутри роутера. Пусто — все интерфейсы
Должен совпадать с ключом на сервере. Без символов # и =
Клиенту обычно нужен STUN, если сервер так настроен
Выключен или ERROR — меньше всего нагрузки и записи на накопитель
Пусто — журнал не ведётся: служба отбрасывает вывод
Дополнительно
Новая сессия с новым портом, если сервер молчит
Для домена или DDNS в адресе сервера, например 300
0 — без случайных байтов, чуть быстрее

Неизвестные параметры, # и = в значениях проверяются до записи — с ними v1.6 не запустится.

Конфиг для импорта в KeeneticOS

      

        
Вставьте конфиг клиента от сервера (секция обфускатора [main] и конфиг WireGuard, в любом порядке). Получится файл AmneziaWG: endpoint — сервер обфускатора, I5 включает встроенный обфускатор. Его можно загрузить в веб-интерфейсе роутера: «Другие подключения» → WireGuard → «Загрузить из файла».
