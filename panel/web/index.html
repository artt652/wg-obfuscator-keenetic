Экземпляры

WireGuard

Сюда подключается WireGuard: Endpoint 127.0.0.1:порт
127.0.0.1 — только внутри роутера. Пусто — все интерфейсы
Должен совпадать с ключом на сервере. Без символов # и =
Клиенту обычно нужен STUN, если сервер так настроен
ERROR или WARN — быстрее всего
Без файла журнал не сохраняется: служба отбрасывает вывод
Дополнительно
Новая сессия с новым портом, если сервер молчит
Для домена или DDNS в адресе сервера, например 300
0 — без случайных байтов, чуть быстрее

Неизвестные параметры, # и = в значениях проверяются до записи — с ними v1.6 не запустится.
